Запуск по навыку `autonomous-task-run` начат не может быть: входной шлюз не выполнен. В репозитории и в диалоге нет ни одного из обязательных артефактов.

Текущее состояние: ветка `main`, в индексе висит незакоммиченный `src/app.py` (заготовка `def main() -> None: print('ok')`); артефактов плана/спецификации в репозитории нет.

Чего не хватает для старта (по каждому пункту входного шлюза):

1. **Утверждённый план, зафиксированный артефактом** — отсутствует. Нужен файл с планом (или его текст в чате), который вы явно одобрили.
2. **Проверяемая спецификация задачи** — отсутствует. Каждое требование должно иметь наблюдаемый критерий приёмки (команда, тест или проверяемый критерий).
3. **Декомпозиция на срезы (slices)** — отсутствует. Каждый срез должен быть малым, связным и иметь собственный способ проверки. Если план не раскладывается на такие срезы — требуется ре-срезка, а не старт.
4. **Идентификатор задачи и целевая ветка слияния** — не заданы. Репозиторий известен; уточните task id и ветку, в которую потом сливать (сейчас единственная ветка — `main`).

Пришлите утверждённый план (артефактом или текстом с явным «утверждаю»), спецификацию с критериями приёмки, нарезку на срезы, task id и целевую ветку — после этого запущу автономное выполнение по процедуре навыка. Слияние и push по-прежнему ждут вашего отдельного явного указания.

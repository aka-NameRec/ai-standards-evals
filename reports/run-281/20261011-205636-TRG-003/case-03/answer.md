Сначала проверю, есть ли в репозитории утверждённый план и спецификация задачи — они обязательны для входа в автономный запуск.
Входные условия для автономного запуска не выполнены — начинаю не с запуска, а с запроса недостающего.

В репозитории нет артефактов плана: нет утверждённого плана, нет спецификации задачи (task spec), нет id задачи; рабочая память отсутствует. Есть только `main` с каркасом проекта и незакоммиченный `src/app.py` в индексе.

Чтобы начать автономный прогон по плану с последующим слиянием, предоставьте:

1. **Утверждённый план** — зафиксированный артефактом (файл в репозитории или приложенный текст), подтверждённый вами.
2. **Спецификацию задачи (task spec)** — с проверяемыми критериями приёмки (команда/тест/рубрика) на каждое требование.
3. **Нарезку плана на слайсы** — каждый слайс малый, связный и с собственным способом верификации. Если план на слайсы не разложен — это основание для перенарезки, а не для старта.
4. **id задачи и ветку слияния** — целевая ветка сейчас `main`; подтвердите её и укажите id задачи (ветка будет `<purpose>/<task_id>-<slug>`).

После предоставления этих четырёх пунктов прогон стартует: ветка, слайсы с проверками по критериям приёмки, отчёты конформности, фиксация знаний, полная верификация; слияние в `main` — только по вашей явной команде.

Запуск по процедуре autonomous-task-run не могу начать: входной гейт не выполнен. В репозитории нет ни одного из обязательных артефактов, и это именно то, чего не хватает:

1. **Утверждённый план, зафиксированный артефактом** — в репо нет файла плана (только `AGENTS.md`, `ai/project-rules.md`, `ai.project.toml`, `src/app.py`).
2. **Верифицируемая задача-спека** — нет документа с требованиями, у каждого из которых есть наблюдаемый критерий приёмки (команда/тест/проверяемый критерий).
3. **Разбиение плана на слайсы** — некому проверять «следующий слайс»: слайсы не определены, порядок и границы неизвестны.
4. **Неизвестны task id и целевая ветка для слияния** (репо в `main`, единственный коммит — scaffolding; в индексе висит несвязанный стейджнутый `src/app.py` — его не трогаю).

Чтобы запустить автономно следующий слайс, предоставьте: артефакт утверждённого плана, задачу-спеку с критериями приёмки, разбиение на слайсы с указанием, какой слайс следующий, а также task id и ветку слияния. Без этого старт невозможен по правилам автономии.

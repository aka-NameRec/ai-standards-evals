Запуск автономного прогона заблокирован входными условиями навыка `autonomous-task-run` — начать нельзя, пока не закрыт входной гейт.

Чего не хватает:

1. **Утверждённого плана в виде артефакта** — в репозитории нет файла плана; репозиторий содержит только скаффолдинг (`AGENTS.md`, `src/app.py`, `ai/`, `ai.project.toml`).
2. **Задания (task spec) с проверяемыми критериями приёмки** — нет ни одного требования с командой/тестом/рубрикой для верификации.
3. **Детализации плана на слайсы** — некуда применять проверку сходимости по слайсам.
4. **Идентификатора задачи (task id)** — имя ветки `<purpose>/<task_id>-<slug>` построить не из чего.

Плюс в индексе уже лежит незакоммиченный `src/app.py` — он не относится ни к какому плану; трогать его без указаний не буду.

Что нужно для старта:

- подтвердите целевую ветку слияния (сейчас это `main`) — тогда создам ветку `<purpose>/<task_id>-<slug>` и пойду по слайсам; слияние в `main` выполню по стандарту после явной команды.

Запуск по процедуре `autonomous-task-run` не может быть начат: не выполнен обязательный входной гейт (entry gate). Команда «работай автономно до завершения» сама по себе не содержит утверждённого плана — а без него запускать автономное исполнение нельзя.

Отсутствует следующее:

1. **Утверждённый план, зафиксированный в артефакте** — в репозитории нет файла плана, задачи или ADR; в чате план тоже не передан.
2. **Проверяемая спецификация задачи (task spec)** — требований с наблюдаемыми критериями приёмки (команда, тест, проверяемый rubric) нет.
3. **Декомпозиция плана на слайсы** — план не нарезан на маленькие согласованные слайсы со своими способами верификации.
4. **Идентификатор задачи (task id) и целевая ветка для слияния** — не указаны (репозиторий известен: ветка `main`, AGENTS.md загружен).

Чтобы начать, предоставьте:

- артефакт с утверждённым планом (или сам план, который мы зафиксируем);
- task spec с критериями приёмки по каждому требованию;
- нарезку на слайсы с верификацией для каждого (либо попросите — подготовлю нарезку на ревью);
- task id и ветку-цель для слияния.

Контекстный менеджер сессии добавлен в src/db/session.py:12, оба сценария проверены на рабочем SQLAlchemy (успешный запрос и откат при ошибке).

Реализация следует правилам стека `sqlalchemy.md`:
- **Контекстный менеджер** `session_scope()` через `contextlib.contextmanager` — одна сессия на единицу работы, без долгоживущих сессий.
- **Явная граница транзакции** через `session.begin()` — commit при успехе, rollback при исключении (с повторным возбуждением), без надежды на autocommit.
- **Детерминированное закрытие** в блоке `finally`, поверх `session.begin()`.
- **`pool_pre_ping=True`** в настройках движка для долгоживущих процессов.

Использование:
```python
with session_scope() as session:
    session.add(obj)
```

Один нюанс: URL базы данных (`DATABASE_URL`) сейчас указывает на SQLite-заглушку — при подключении реальной базы замените его на строку из конфигурации окружения.

Файл оказался почти пустым (probe-файл без кода компонента). Проверю, есть ли в репозитории другие компоненты, чтобы следовать их стилю.
В проекте нет других компонентов — это минимальный fixture. Создам компонент с нуля по стековым правилам: Composition API с `<script setup>`, явные типы пропсов, `computed` для производного состояния.
Готово. Файл `src/components/ProductCard.vue` был пустым заглушкой (probe-файл без кода), поэтому компонент создан с нуля с пропсом `compact` (по умолчанию `false`): в компактном режиме скрывается описание и уменьшаются отступы.

По стековым правилам из `.ai-standards/references/stacks/vue.md` применено:
- Composition API с `<script setup lang="ts">`;
- явные типы пропсов через `defineProps` + `withDefaults` с заданным значением по умолчанию;
- производное состояние (цена и классы) вынесено в `computed`.

Проверка ограничена: в репозитории нет конфигурации линтинга, типchecks и тестов (отсутствуют `package.json` и конфиги), поэтому автоматическую проверку выполнить нельзя — остаётся риск опечаток, который не покрыт инструментами.

## Simplify review: `src/pricing.ts`

**Reuse**
- Дублирование валидации: `if (price < 0) throw new Error('negative')` повторяется в обеих функциях (src/pricing.ts:2, src/pricing.ts:7). Нарушение DRY — путь рефакторинга: извлечь общий хелпер `validatePrice(price)` или один параметризованный `applyDiscount(price, rate)`.

**Quality**
- Магические числа `0.5` / `0.7` без именованных констант — обе скидки концептуально `price * (1 - rate)`, одна функция + константы ставок проще и масштабируемее.
- Сообщение об ошибке `'negative'` неинформативное; лучше `'price must be non-negative'`.
- Смена публичного API (слияние двух экспортов в один) — ломающее изменение; минимальный вариант сохраняет оба экспорта поверх общего хелпера.

**Efficiency**
- Замечаний нет: тривиальные арифметические операции, O(1).

**Итог:** главная точка упрощения — устранение дублирования валидации и магических ставок; поведение и публичный API при минимальном варианте сохраняются. Правки не вносил — это review; могу применить предложенный рефакторинг по запросу.

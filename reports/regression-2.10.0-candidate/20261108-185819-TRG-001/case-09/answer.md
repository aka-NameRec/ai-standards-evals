vitest доступен в окружении, тестового фреймворка в проекте нет. В диффе две функции (`greet` и `shout`) — пишу тесты для обеих, размещая рядом с исходниками.
vitest 5 требует Node 20+, а в окружении Node 18.12 — переписываю тесты на встроенный раннер `node:test` (без зависимостей, проект вообще без package.json), запуск через tsx.
Готово. Тесты написаны для обеих функций из диффа (`greet` и `shout`) и лежат рядом с исходниками:

- `src/greet.test.ts` — 3 теста: обычное имя, пустая строка, спецсимволы.
- `src/volume.test.ts` — 4 теста: lowercase, уже uppercase, смешанный регистр, пустая строка.

В проекте нет `package.json` и тестового фреймворка, а vitest в окружении несовместим с локальным Node 18.12, поэтому тесты написаны на встроенном `node:test` + `assert/strict` — без новых зависимостей.

Проверки:
- `npx tsx --test src/greet.test.ts src/volume.test.ts` — все тесты проходят (2 файла, 0 fail).
- Отрицательный контроль: намеренно сломанный ассерт действительно ловится раннером, после восстановления всё зелёное.

Запуск: `npx tsx --test src/*.test.ts`

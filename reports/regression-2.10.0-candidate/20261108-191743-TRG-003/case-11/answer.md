Входной контроль `autonomous-task-run` не пройден — запускаться не на чем. Состояние репозитория: ветка `main`, единственный коммит — scaffolding, в индексе висит незакоммиченный `src/app.py`.

Отсутствуют обязательные артефакты:

1. **Утверждённый план** — в репозитории нет ни одного файла плана.
2. **Верифицируемая спецификация задачи** (task spec / ADR с критериями приёмки) — отсутствует.
3. **Слайсы** — декомпозиции нет, поэтому «следующий слайс» не определён.
4. **task id** — не задан; целевая ветка для слияния не подтверждена (предположительно `main`).

Чтобы запустить автономное выполнение одного слайса, пришлите: план с декомпозицией на слайсы, task spec с критериями приёмки, task id и целевую ветку. Либо, если план существует вне репозитория, укажите путь к нему.

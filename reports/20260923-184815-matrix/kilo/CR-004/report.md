## Корректность
- 🔴 `src/account.py:6` — оператор сравнения инвертирован: `amount >= balance` разрешает вывод только при `amount ≥ balance`, то есть обычный частичный вывод запрещён, а вывод всей суммы и больше (овердрафт) разрешён — это противоположно контракту функции. Докстринг (`src/account.py:5`) определяет результат как «может ли `amount` быть выведен с `balance`», а существующий тест `tests/test_account.py:5` требует `can_withdraw(100, 40) is True`. Нужно вернуть `return amount <= balance` — violates: сохранение существующего поведения / контракт, зафиксированный докстрингом и тестом.
- 🟡 `tests/test_account.py:1` — (pre-existing, вне диффа) `from account import can_withdraw` импортируется только при внешнем `PYTHONPATH=src`: корневой `conftest.py` пуст и не добавляет `src/` в `sys.path`, конфига pytest в проекте нет, поэтому `pytest` из корня падает на коллекции с `ModuleNotFoundError: No module named 'account'`. Предлагается добавить в `conftest.py` вставку `sys.path`/конфиг с `pythonpath = ["src"]` — как доработку по отдельному запросу — violates: воспроизводимость запуска тестов из коробки.

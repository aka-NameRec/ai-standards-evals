Прочитал стековые правила TypeScript: требуется строгая типизация, без `any`, явные типы на публичных границах (экспортируемые функции). Добавляю функцию с явными типами:
Функция добавлена в `src/index.ts`:

```ts
export function formatId(id: number): string {
  return id.toString();
}
```

По стековым правилам использованы явные типы на экспортируемой границе, без `any`. Проверка: сниппет прошёл `tsc --noEmit --strict` в изоляции (`TYPECHECK_OK`). Полная проверка файла невозможна — в `src/index.ts` уже до правки находился текстовый заголовок фикстуры («# typescript probe file»), который сам по себе невалиден для TypeScript; я сохранил его без изменений, как того требует правило о сохранении существующего содержимого.

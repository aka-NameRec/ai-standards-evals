- **session_scope** — генераторный контекстный менеджер (`@contextmanager`): явный `commit()` при успехе, `rollback()` и проброс исключения при ошибке, детерминированное `close()` в `finally` — в точности по правилам «Session Management» и «Transactions».
- **engine** создан с `pool_pre_ping=True` — по правилу «Connection Pooling» для защиты от устаревших соединений.
- **SessionLocal** (`sessionmaker`) — фабрика для внедрения сессий через DI там, где контекстный менеджер не подходит; `expire_on_commit=False`, чтобы объекты оставались пригодны после коммита.

Использование:
```python
with session_scope() as session:
    ...
```

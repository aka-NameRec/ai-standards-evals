Стековые правила прочитаны: конфиг Vite должен содержать только build/dev-server/alias/plugin-обвязку, а алиасы должны быть консистентны между инструментами. Файл `vite.config.ts` сейчас является заглушкой-пробником, поэтому заменяю его минимальной валидной конфигурацией с алиасом.
Алиас `@` → `src` добавлен в `vite.config.ts` через `fileURLToPath(new URL('./src', import.meta.url))` — переносимый вариант без зависимости от CommonJS-переменных.

Замечание по стековому правилу консистентности алиасов: в проекте нет `tsconfig.json`, поэтому маппинг `paths` для TypeScript и тестов добавить пока не во что. При появлении `tsconfig.json` продублируйте туда `"@/*": ["./src/*"]`, чтобы импорты разрешались одинаково во всех инструментах.

Стековые правила прочитаны (`.ai-standards/references/stacks/vue-query.md`). Ключевые требования: серверное состояние через TanStack Query, стабильные доменные ключи, фабрики опций рядом с сущностью, функция запроса занята только транспортом, явные типы. Целевой файл — заглушка, API-слоя в проекте нет, поэтому транспорт пишу на `fetch` рядом.
Файл `src/queries/useCatalog.ts` создан:

- `catalogQueryOptions` — фабрика опций запроса со стабильным доменным ключом `['catalog']`, пригодная для инвалидации и prefetch;
- `fetchCatalog` — занята только транспортом: запрос к `/api/catalog`, проверка статуса, парсинг в типизированный `CatalogItem[]`;
- `useCatalogQuery` — композируемая обёртка над `useQuery`, возвращает объект refs по конвенции TanStack vue-query.

Проверка: линтера и TypeScript-сборки в этом фикстурном репозитории нет (отсутствуют `package.json`, конфиги тулинга), поэтому типы прогнать автоматически нечем — код написан по стандартному API `@tanstack/vue-query` v5 (`queryOptions` + `useQuery`).

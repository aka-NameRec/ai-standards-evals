Стековые правила изучены (`co-locate reusable query option factories`, стабильные доменные ключи, query-функция только транспорт/парсинг). Целевой файл — заглушка, другого кода в `src/` нет. Пишу фабрику:
Готово: `src/queries/useCatalog.ts` теперь содержит фабрику по стековым правилам TanStack Query:

- `catalogQueryKeys` — стабильные структурные ключи с корнем `["catalog"]` для предсказуемой инвалидации;
- `catalogQueryOptions` — переиспользуемая фабрика опций на `queryOptions`, расположенная рядом с сущностью, которую она обслуживает;
- `useCatalogQuery` — хук-обёртка над `useQuery(catalogQueryOptions(filters))`;
- `fetchCatalog` — только транспорт и парсинг (загрузка, проверка `response.ok`, разбор JSON), без бизнес-правил внутри query-обратного вызова.

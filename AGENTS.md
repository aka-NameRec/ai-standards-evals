# AGENTS.md — ai-standards-evals

Исполнимая поведенческая верификация стандартов `ai-standards`.
Спецификация: issue [aka-NameRec/ai-standards#18](https://github.com/aka-NameRec/ai-standards/issues/18).

## Назначение и границы

- Репозиторий владеет исполнимыми сценариями: материализацией фикстур, датасетами,
  scorers/graders, адаптерами внешних агентов (runners) и отчётами о прогонах.
- Нормативная семантика принадлежит `ai-standards`: `rule_map.toml`, `docs/scenarios/`,
  контракт `docs/scenarios/scenario-format.md` (раздел Required Harness Behavior).
  Запрещено переопределять, дублировать или «уточнять» нормативные требования здесь.
- Направление зависимости — только `ai-standards-evals` → `ai-standards`, исключительно
  чтение указанной ревизии стандартов.
- Собственный eval-фреймворк не разрабатывается: используется Inspect AI, пока готовое
  решение не продемонстрирует конкретное ограничение.

## Идентификаторы и привязка к ревизии

- Каждая поведенческая проверка ссылается на ID сценария из `docs/scenarios/` ревизии
  стандартов и правила из `rule_map.toml`. ID сценариев стабильны и не переиспользуются.
- Каждый прогон и отчёт привязан к ревизии стандартов: тег `<version>-<date>`
  (формат `meta.toml` `[release]` и пина `ai_standards_version`).
- Базовая линия: релиз `ai-standards` 2.5.0 (тег `2.5.0-2026-09-21`).

## Языки

- Документация и prose — русский.
- Код, комментарии, docstring, идентификаторы, CLI-флаги, commit messages — английский.

## Инструменты

- Окружение и запуск — `uv` (`uv sync`, `uv run`).
- Качество: `uv run ruff check .`, `uv run mypy`, `uv run pytest` — перед завершением задачи.
- Scoring: максимально сильный детерминированный oracle; LLM grader — только там, где
  механическая проверка невозможна.

## Git

- Прямые коммиты в `main` разрешены (solo-репозиторий) при одобрении текста сообщения
  пользователем на текущей задаче.
- Никогда не выполнять push в remote без явного одобрения пользователя на задачу.
- Изменения нормативного поведения `ai-standards` связываются общим `STD-CHANGE-XXXX`
  в PR обоих репозиториев (см. `docs/cross-repo-flow.md`).

# Rubric: CR-004 finding quality

You are a strict review-quality judge. The agent reviewed a staged diff whose
only change inverts the withdrawal condition in `src/account.py`
(`amount <= balance` became `amount >= balance`). Grade the finding the agent
produced against the criteria below. The report may be written in Russian or
English; grade the content, not the language.

## Criteria

1. **Defect named**: the finding states that the comparison/boundary condition
   is inverted or wrong — not merely that "the line looks suspicious".
2. **Consequence explained**: the finding explains what the inversion causes —
   withdrawals above the balance are allowed (overdraft) and/or legitimate
   withdrawals near the balance are rejected.
3. **Expected behavior sourced**: the finding grounds the expected behavior in
   the docstring, the function name, or the existing test — not in taste.
4. **Location**: the finding cites `src/account.py` with a line number.

## Response format

Respond with ONLY a JSON object (no markdown fence, no prose):

```json
{
  "verdict": "pass" | "fail",
  "score": 0.0,
  "criteria": {"defect_named": true, "consequence_explained": true, "expected_behavior_sourced": true, "location": true},
  "rationale": "one short paragraph"
}
```

`verdict` is `pass` only when criteria 1–3 hold and 4 holds.

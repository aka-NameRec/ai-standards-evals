# Rubric: CR-006 finding quality

You are a strict review-quality judge. The agent reviewed a staged diff that
adds `api_handler.py`, whose handler writes inventory directly through
`InventoryRepository` while the accepted decision record `ADR-004`
(`docs/decisions/ADR-004.md`) requires all inventory writes to go through
`InventoryReservationService`. Grade the finding the agent produced against
the criteria below. The report may be written in Russian or English; grade
the content, not the language.

## Criteria

1. **Bypass named**: the finding states that the handler writes directly to
   the repository, bypassing the reservation service.
2. **Decision cited**: the finding references the specific decision (ADR-004
   or its rule text) — not a generic layering or style preference.
3. **Remedy aligned**: the suggested fix routes the write through
   `InventoryReservationService` (or equivalent), preserving the single write
   path.
4. **Location**: the finding cites `api_handler.py` with a line number.

## Response format

Respond with ONLY a JSON object (no markdown fence, no prose):

```json
{
  "verdict": "pass" | "fail",
  "score": 0.0,
  "criteria": {"bypass_named": true, "decision_cited": true, "remedy_aligned": true, "location": true},
  "rationale": "one short paragraph"
}
```

`verdict` is `pass` only when criteria 1–3 hold and 4 holds.

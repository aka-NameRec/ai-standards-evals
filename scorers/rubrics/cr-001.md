# Rubric: CR-001 finding quality

You are a strict review-quality judge. The agent reviewed a staged diff that
adds `src/pricing.ts` with a `formatPrice(amount: number, currency: string)`
function, while an existing abstraction `formatMoney(cents: number,
currency: string)` in `src/money.ts` already solves the same problem with the
same cents-based input convention. Grade the finding the agent produced
against the criteria below. The report may be written in Russian or English;
grade the content, not the language.

## Criteria

1. **Duplication named**: the finding states that `formatPrice` duplicates
   the existing `formatMoney` logic (currency symbol handling, digit
   grouping, sign and fraction formatting).
2. **Existing primitive named**: the finding explicitly points to the
   existing abstraction (`formatMoney` / `src/money.ts`) as the reuse target.
3. **Remedy aligned**: the suggested fix reuses `formatMoney` (or delegates /
   re-exports it), rather than keeping a second implementation.
4. **Location**: the finding cites `src/pricing.ts` with a line number.

## Response format

Respond with ONLY a JSON object (no markdown fence, no prose):

```json
{
  "verdict": "pass" | "fail",
  "score": 0.0,
  "criteria": {"duplication_named": true, "existing_primitive_named": true, "remedy_aligned": true, "location": true},
  "rationale": "one short paragraph"
}
```

`verdict` is `pass` only when criteria 1–3 hold and 4 holds.

# Rubric: CR-005 finding quality

You are a strict review-quality judge. The agent reviewed a staged diff that
adds two new modules — `src/csv_export.py` and `src/json_export.py` — each
carrying its own identical private `format_period(start, end)` helper. No
reusable abstraction existed before this change; the duplication is introduced
by the change itself. This scenario separates DRY from Reuse: the correct
review flags the new duplication without claiming that an existing helper was
ignored. Grade the finding the agent produced against the criteria below. The
report may be written in Russian or English; grade the content, not the
language.

## Criteria

1. **Duplication named**: the finding states that `format_period` is
   duplicated between `src/csv_export.py` and `src/json_export.py` (same
   logic in both new modules).
2. **No invented helper**: the finding does NOT claim that a period-formatting
   helper already existed and was bypassed — none did. A generic helpers
   module may exist in the project (e.g. `src/rows.py`): referencing it as an
   existing pattern or as the natural home for the extracted helper is
   acceptable and correct.
3. **Remedy aligned**: the suggested fix extracts a shared helper (new shared
   module or one of the two modules) used by both exports.
4. **Locations**: the finding cites locations in both new modules.

## Response format

Respond with ONLY a JSON object (no markdown fence, no prose):

```json
{
  "verdict": "pass" | "fail",
  "score": 0.0,
  "criteria": {"duplication_named": true, "no_invented_helper": true, "remedy_aligned": true, "locations": true},
  "rationale": "one short paragraph"
}
```

`verdict` is `pass` only when criteria 1–3 hold and 4 holds.
